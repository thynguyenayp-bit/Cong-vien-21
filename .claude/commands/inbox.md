# /inbox

Dọn dẹp thư mục `00 - Inbox` và các ghi chú rời chưa phân loại.

Bước:
1. Liệt kê tất cả file trong `00 - Inbox/`.
2. Đọc nội dung từng file.
3. Đề xuất phân loại mỗi ghi chú vào đúng thư mục PARA:
   - `01 - Projects/` — việc có deadline / mục tiêu rõ
   - `02 - Areas/` — trách nhiệm lâu dài
   - `03 - Resources/` — tài liệu tham khảo
   - `04 - Archive/` — đã xong hoặc không còn cần thiết
   - `05 - Daily Notes/` — ghi chú ngày
4. Đề xuất tên file mới (theo quy ước: PRJ - ..., Họ Tên, YYYY-MM-DD, DEC - ...).
5. Thêm wikilink tới các note / người / dự án liên quan nếu có.
6. Hỏi người dùng duyệt trước khi di chuyển / đổi tên file.

**Không tự động di chuyển file khi chưa được xác nhận.**
