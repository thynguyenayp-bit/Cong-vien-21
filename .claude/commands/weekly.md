# /weekly

Chạy Weekly Review cho tuần hiện tại.

Bước:
1. Tạo file `05 - Daily Notes/Weekly Review - YYYY-[W]ww.md` theo mẫu `06 - Templates/Template - Weekly Review.md` (nếu chưa có).
2. Tổng hợp các task đã hoàn thành trong 7 ngày qua.
3. Liệt kê task còn tồn / quá hạn.
4. Liệt kê dự án đang active.
5. Gợi ý 3 ưu tiên tuần tới dựa trên:
   - Các việc quá hạn / sắp đến hạn
   - Các dự án active có deadline gần
   - Mục tiêu sếp đang quan tâm (tham khảo [[My-Role]])
6. Kiểm tra `00 - Inbox` và nhắc dọn nếu còn file.
7. Trả về tóm tắt ngắn gọn bằng tiếng Việt.
