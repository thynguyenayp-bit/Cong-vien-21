# /daily

Tạo ghi chú ngày hôm nay trong `05 - Daily Notes/` theo mẫu `06 - Templates/Template - Daily Note.md`.

Bước:
1. Xác định ngày hôm nay (YYYY-MM-DD).
2. Nếu file `05 - Daily Notes/YYYY-MM-DD.md` chưa tồn tại, tạo mới từ template.
3. Kéo các `#task` có `due <= hôm nay` chưa hoàn thành vào mục "Việc đến hạn hôm nay".
4. Gợi ý 3 ưu tiên hôm nay dựa trên task quá hạn / đến hạn và các dự án active.
5. Trả về tóm tắt ngắn gọn bằng tiếng Việt.
