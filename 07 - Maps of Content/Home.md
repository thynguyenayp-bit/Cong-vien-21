## Bắt đầu nhanh mỗi ngày
1. Tạo daily note: `/daily` hoặc *"tạo daily note hôm nay"*.
2. Ghi mọi thứ cần nhớ / làm vào Daily Note hoặc `00 - Inbox`.
3. Viết task dạng `- [ ] ... #task 📅 YYYY-MM-DD 🔼` để Dashboard tự gom.
4. Cuối tuần chạy `/weekly` để review.

## Lệnh AI thường dùng
| Lệnh | Khi nào |
|------|---------|
| `/daily` | Sáng — tạo ghi chú ngày và kéo task đến hạn |
| `/inbox` | Vài ngày/lần — dọn Inbox về PARA |
| `/weekly` | Cuối tuần — review tuần và lên kế hoạch tuần tới |
| `/distill` | Sau khi giải xong việc khó — chắt lọc bài học |
