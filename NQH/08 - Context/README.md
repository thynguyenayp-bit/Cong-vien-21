# ⚙️ Context — Để AI hiểu bạn (Hermes)

> Nơi mô tả **bạn** cho AI agent: công cụ/stack bạn dùng, cách bạn muốn làm việc, bối cảnh công việc. AI đọc đầu mỗi phiên để cá nhân hóa.

## Có gì ở đây
- [[My-Tech-Stack]] — công cụ/ngôn ngữ/quy ước bạn dùng (nếu làm kỹ thuật).
- [[Working-Preferences]] — cách bạn muốn AI hỗ trợ.

## Cách dùng
- Khi đổi công cụ/cách làm → **sửa file ở đây**. Phiên sau AI tự dùng.
- Giữ ngắn gọn, cập nhật dần.
